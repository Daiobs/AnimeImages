项目结构
project/
  templates/
    base.html                  # 全站统一布局
  static/
    css/app.css                # 全站样式
    js/app.js                  # 全站通用 JS

  search_app/
    templates/search_app/
      index.html               # 图库首页
      results.html             # 图库搜索结果

  xhs_download/
    templates/xhs_download/
      index.html               # 小红书解析下载页面
    services/
      parser.py                # 解析小红书链接
      downloader.py            # 下载、保存、格式转换
      image_url.py             # 图片 URL 规范化
    views.py
    urls.py

  submissions/
    models.py                  # 后续保存解析记录、下载记录
  

views.py：只负责接收请求、返回页面/JSON
services/parser.py：只负责解析链接
services/downloader.py：只负责下载保存
templates：只负责展示
static/js：只负责交互
