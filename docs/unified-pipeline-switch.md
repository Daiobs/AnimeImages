# 统一管线：按平台切换（契约第 3 步）

契约见 [unified-pipeline.md](architecture/unified-pipeline.md)。本页记录切换开关怎么用、切换后用户看到什么、已知限制。

## 开关

- 后台 → `统一管线路由`（`/admin/xhs_download/pipelineroute/`），每个平台一行，行由迁移写入。
- `使用统一管线` 打开后，该平台的新解析走统一管线；关闭后立即回到原路径，已经发出的选择器也随之失效（需要重新解析）。
- 读不到这张表（例如代码先于迁移上线）按“关闭”处理。
- 目前只有抖音有统一实现；其他平台的行即使打开也不生效。

抖音的默认路由（迁移 0033，默认关闭）：

| 配置 | 值 |
|---|---|
| 顺序 | 天天解析 → KuKuTool → Native |
| 策略 | `floor_and_upgrade`，保底 Native |
| 前台预算 / 升级窗口 | 8 秒 / 8 秒 |
| 冷却 | 基础 10 秒，按连续失败翻倍，上限 300 秒；每个进程各自计算，成功一次清零 |

- 天天和 KuKuTool 只在用户可用原画/超清时参与，照旧扣每分钟额度；KuKuTool 需要配置 sidecar。
- Native 从一开始并行运行，拿到整个窗口。
- 首选在升级窗口内成功，就展示首选的结果；首选都失败，或窗口结束时首选仍没有结果，就展示 Native。页面等到结果确定才返回，不会先展示 Native 再升级。

## 用户看到什么

- **图文：** 与原来一样的图片卡片，可自由选择，下载原图。
- **视频：** “选择清晰度”列出展示结果的全部清晰度。
  - 同一文件的多个镜像只列一次；
  - 抖音带水印的 `download_addr` 不列出；
  - 默认选最好的一档（原画优先，其次分辨率、码率）。
- **下载：** 点下载时，服务端只请求每个镜像的第一个字节，挑出浏览器能跨域读取（CORS）的镜像，返回一个普通视频条目。浏览器经现有 Service Worker 流式保存，失败退回浏览器整块保存。服务端不转交正文。

## 已知限制

- 单独的音频（抖音原声）暂不提供下载：现有浏览器下载不支持非上游来源的单独音频。
- 天天不给大小时，页面显示“大小未知”，下载时按实际大小保存。
- 所有镜像都不允许跨域读取时，提示换一档清晰度。契约第 8 节第 1 条的“失败后改由服务器转交”尚未接入统一管线。
- 选择器的引用 30 分钟内有效（不超过 CDN 链接的过期时间），过期后需要重新解析。
